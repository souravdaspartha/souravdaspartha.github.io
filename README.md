# Sourav Das Partha — Portfolio

This repository contains the source files for my academic and professional portfolio.

**Website:** [souravdaspartha.github.io](https://souravdaspartha.github.io/)

I am a transport planner and spatial data analyst based in Dhaka, Bangladesh. My work focuses on travel demand modeling, public transport, road safety, traffic and intersection analysis, and GIS-based planning in rapidly urbanizing and data-constrained contexts.

## Portfolio Contents

- **Projects:** Selected professional transport and urban planning assignments
- **Maps:** Travel demand, road safety, public transport, environmental, and intersection-design outputs
- **Research:** Current research interests, ongoing studies, and academic theses
- **CV:** Education, professional experience, technical skills, and training

## Areas of Interest

- Travel demand modeling under data scarcity
- Public transport and informal mobility
- Transport accessibility and disadvantage
- Road crash analysis and spatial safety assessment
- Sustainable and climate-responsive urban mobility
- Land-use and transport integration

## Methods and Tools

Python · R · Stata · Biogeme · TransCAD · ArcGIS Pro · QGIS · SIDRA Intersection · Civil 3D

## Confidentiality

Some portfolio materials are derived from professional consulting assignments. Only non-confidential descriptions, aggregated results, and permitted visual outputs are presented. Client datasets and restricted project materials are not included in this repository.

The website is built with Jekyll and GitHub Pages using the Academic Pages framework.
